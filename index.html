Ethereum in 30 seconds

Ethereum L1 is the settlement layer: a global computer where smart contracts run and every transaction is secured by the full network. It is powerful but capacity-limited, so most everyday activity moves to Layer 2 rollups — chains that execute transactions cheaply off L1 and post proofs/data back to Ethereum, inheriting its security. Since EIP-1559, every L1 transaction burns a base fee that floats with demand, plus an optional priority fee (tip) — the estimator below models exactly that.

Base is Coinbase's L2, built on the OP Stack / Superchain. Unichain is Uniswap's L2, built for DeFi and cross-chain liquidity. Robinhood Chain is Robinhood's permissionless L2 for onchain finance and tokenized real-world assets, built on Arbitrum technology with ETH as its gas token — live per its official documentation. Same EVM, same Solidity, same tooling (viem, ethers.js, Foundry) across all of them — which is why one builder hub can cover all four.

Tools — exact, local, offline

Wei converter (ETH ⇄ gwei ⇄ wei)

Exact BigInt conversion — no floating point, ever. 1 ETH = 109 gwei = 1018 wei.

EIP-55 address inspector

Paste an address to validate its form and EIP-55 checksum (Keccak-256 computed locally in your browser). Try mine: 0x4b48c98cd9d99d00dafe5cc4bb9e965345c5b15a

Function selector & event topic calculator

Type a canonical function or event signature — the 4-byte function selector (used in calldata) and the 32-byte event topic0 (used in logs) are both Keccak-256 hashes of it, computed locally. Works for any contract on Ethereum, Base, Unichain, or Robinhood Chain — the EVM is the same everywhere.

CREATE2 address calculator (EIP-1014)

CREATE2 deploys a contract to an address you can know in advance: the last 20 bytes of Keccak-256 of 0xff ++ deployer ++ salt ++ keccak256(init code). Same deployer, salt and init code → same address on Ethereum, Base, Unichain and Robinhood Chain — the basis for counterfactual wallets and cross-chain deployments. Defaults below are EIP-1014's own Example 0. This only computes the address locally; nothing is deployed.

EIP-1559 gas cost estimator

A wallet-convention model, not live data: expected cost uses base + priority fee; max cost uses maxFeePerGas = 2×base + priority. A simple transfer is 21,000 gas.
